# Provenance and scope

This is an unofficial community patch for the first Star Wolves.
It is not affiliated with or endorsed by the game's developers or publisher.

This package contains the patch's assembly sources, replacement-byte records,
documentation, and reproducible Python tooling. It does not contain the game's
original source tree, assets, or a complete original or patched executable.
Users supply their own supported original EXE.

The cursor and sensitivity assembly sources were recovered from the original
patch-development archives. The readable resolution and startup assembly was
reconstructed from the archived released bytes. The Python publication tools
were written later and checked against the final archived v1.1.0 executable.
All four source fragments reproduce the corresponding machine code exactly.

Game names and original game software belong to their respective owners.
No license to the original game is granted by publishing this tooling.
